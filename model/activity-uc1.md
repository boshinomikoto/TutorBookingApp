# Activity Diagram — UC1 «Зареєструвати учня»

Автор: Максим.

```mermaid
flowchart TD
    A([Початок]) --> B[Відкрити форму додавання учня]
    B --> C["Ввести ім'я, телефон, нотатки"]
    C --> D{"Повне ім'я вказано?"}
    D -- Ні --> E["Повідомити про обов'язкове поле"]
    D -- Так --> F[Зберегти учня]
    F --> G[Показати учня у списку]
    G --> H([Успішне завершення])
    E --> I([Завершення з помилкою])
```
